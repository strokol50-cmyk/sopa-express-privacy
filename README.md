# Publicar la política con GitHub Pages

1. En GitHub, creá un repositorio **público** llamado `sopa-express-privacy`.
2. Subí `index.html` desde esta carpeta a la raíz del repositorio y confirmá el cambio.
3. Abrí **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**, seleccioná `main` y la carpeta `/ (root)`, y guardá.
5. GitHub mostrará una URL con este formato: `https://TU_USUARIO.github.io/sopa-express-privacy/`.

Copiá la URL publicada para pegarla en la sección **Política de privacidad** de Google Play Console. La página incluye `strokol50@gmail.com` como contacto público.
